# RFR-LME

This repository contains code to produce RFR-LME indicators of ocean acidification in eleven U.S. large marine ecosystems (LMEs).

Instructions:
1. Download most recend SOCAT .tsv file from socat.info and add to repository called 'SOCATvYYYY' within RFR-LME folder.
2. Define vrs in Line 3 of create_RFR_LME.m as 'SOCATvYYYY'.
3. Define dpath in Line 3 of create_RFR_LME.m as wherever you want the downloaded predictor variables to be stored.
4. Run create_RFR_LME.m.
